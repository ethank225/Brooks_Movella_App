Unit Tests

Test target structure, coverage, and testability patterns.

Running Tests

Tests live in the Brooks-Movella-AppTests target. Run from Xcode via Product → Test (⌘U), or from the command line:

xcodebuild test \
  -scheme "Brooks-Movella-App" \
  -destination 'platform=iOS Simulator,name=iPhone 15'

No SDK or Bluetooth is needed — all tests exercise pure logic extracted from the managers.

Testability Patterns

Dependency injection for isolation

Both RunnerStore and SensorNameStore are singletons with static let shared. To test without polluting the shared instance:

  • RunnerStore accepts an optional fileURL in its initializer. Tests pass a temp file path; production uses the default Documents/runners.json.
  • SensorNameStore accepts a UserDefaults instance and key. Tests pass UserDefaults(suiteName:) for isolation; production uses .standard.

Extracted static functions

DotManager.aggregateSessionPhase(from:) was extracted from a computed property into a static function. This lets tests call it with arbitrary [String: SessionPhase] dictionaries without needing to instantiate DotManager (which requires the Movella SDK).

Pure enums

SessionPhase and ConnectionPhase are nonisolated enums with no SDK dependencies. Their computed properties (isBusy, isError, isSyncActive, isFailed, isConnected) can be tested directly with zero setup.
